# ЛР4: ветки Git, Pull Request, Code Review

Учебный репозиторий для отработки командной разработки. Каждый участник работает
в своей ветке `feature/<фамилия>` и вносит изменения в `main` только через
Pull Request после Code Review.

## Порядок работы

1. Склонировать репозиторий: `git clone https://github.com/vlasovrustam07-cpu/trpo-lab4.git`.
2. Создать свою ветку: `git checkout -b feature/<фамилия>`.
3. Внести изменения, сделать commit и push ветки.
4. Открыть Pull Request в `main`, пройти Code Review, выполнить merge.
